# SC11-Water-Quality-Potability-Example

# Data Dictionary

| Field | Simple meaning | Type/unit | Starter rule |
| :--- | :--- | :--- | :--- |
| `sample_id` | Unique water sample | text | WTR-001, WTR-002, ... |
| `ph` | Acidity/alkalinity | number | 0 to 14 |
| `hardness` | Mineral content | mg/L | Positive number |
| `solids` | Total dissolved solids | ppm | Positive number |
| `sulfate` | Dissolved sulfates | mg/L | Positive number |
| `turbidity` | Water clarity | NTU | Positive number |
| `potability_target` | Known result | category | 1 (Potable), 0 (Not Potable) |
